# Барахолка — бот сбора и публикации вакансий

Собирает удалённые вакансии, отбирает по критериям, ставит оценку 1–5 и публикует пост в канал.
Работает без сторонних библиотек: только `multitool-node` (он уже стоит в MultiTool).

## Что отбирается

Жёсткие условия (без них вакансия не попадает в очередь):

- работа из дома: формат `REMOTE` или прямое указание удалёнки;
- самозанятость, ИП или ГПХ: поле вакансии hh «гражданско-правовой договор» либо текст объявления;
- не банк и не оператор связи (по названию компании и по названию вакансии);
- не разъездная работа: курьер, водитель, экспедитор, «выезды на объекты» отсекаются;
- опыт не больше 6 лет.

Оценка:

| Условие | Оценка |
|---|---|
| без опыта, звонков нет | 5 |
| опыт 1–3 года, звонков нет | 4 |
| без опыта, но со звонками | 3 |
| опыт 1–3 года и звонки | 2 |

Публикуется всё, что набрало `MIN_SCORE` и выше (по умолчанию 3).

## Источники

- **hh.ru** — поиск `schedule=remote`, `area=212` (Тольятти). API вакансий отдаёт 403, поэтому
  читается HTML-выдача hh, из неё берутся ID, затем открывается карточка каждой вакансии.
- **opendata.trudvsem.ru** — только первая сотня: `offset` больше 0 отвечает 500.
- **Авито** — без браузера отдаёт антибот-страницу (429/439), источник пропускается без падения.

## Установка

1. Скопировать `.env.example` в `.env`.
2. В `BOT_TOKEN` вписать токен от [@BotFather](https://t.me/BotFather).
3. Бота добавить в канал администратором (право публиковать сообщения).
4. В `CHANNEL` вписать `@username` канала или числовой id вида `-1001234567890`.
5. В `ADMIN_ID` — свой id, туда придут сообщения об ошибках (необязательно).

## Запуск

Бот работает постоянно: раз в `COLLECT_INTERVAL_MIN` минут обходит площадки, публикует
подходящее и одновременно слушает команды.

```
multitool-node "C:\Users\Public\MultiTool-rabota\Chat-27\baraholka-bot\bot.cjs"
```

Разовый прогон без ожидания команд:

```
multitool-node "...\run.cjs"
```

Отдельные команды:

```
:: только собрать, ничего не публиковать
multitool-node "...\collect.cjs"

:: посмотреть, что уйдёт в канал
multitool-node "...\publish.cjs" --dry

:: слушать только команды, без публикаций
multitool-node "...\listener.cjs"
```

## Запрос списка в канале

В канале (или в личке с ботом) отправить:

- `список` — бот прямо сейчас обходит hh, Трудвсем и Авито и присылает все вакансии
  за последние 24 часа с оценкой от 1 до 5;
- `список 4` — только с оценкой 4 и 5.

Список собирается заново, из живых площадок, а не из сохранённого журнала.
Обход занимает до двух минут: бот сначала пишет «Обхожу площадки…», потом присылает отчёт.
Повторный запрос в течение трёх минут отдаётся из кеша, чтобы не гонять площадки зря.

Если запрос сделан постом в канале, ответ приходит в личку (`ADMIN_ID`); без `ADMIN_ID` —
постом в канале. Отвечает только владелец: чужие запросы бот игнорирует.

## Файлы состояния (папка `data`)

- `seen.json` — всё, что уже просмотрено, повторно не публикуется.
- `queue.json` — очередь постов, готовая к отправке.
- `manual-queue.json` — посты, добавленные руками; уходят первыми.
- `vacancies.json` — журнал оценённых вакансий за 7 дней (для сверки, в отчёте не используется).
- `published.json` — история публикаций с id сообщений.
- `offset.json` — позиция чтения команд Telegram.
- `log.txt` — журнал отправок.

## Автозапуск

`install-task.cmd` создаёт задачу планировщика «BaraholkaBot»: запуск при входе в систему,
работает постоянно. Установить: правый клик → «Запустить от имени администратора». Удалить:

```
schtasks /Delete /TN BaraholkaBot /F
```

## Перенос на хостинг

Папка самодостаточна, зависимостей нет — нужен только Node.js 16+ (работает и на обычном
Node, и на `multitool-node`; если в Node нет глобального `fetch`, включается запасной
клиент на `https`).

1. Загрузить на сервер все файлы, кроме `.env` и папки `data`.
2. Создать `.env` из `.env.example` и вписать `BOT_TOKEN`, `CHANNEL`, `ADMIN_ID`.
3. Запустить `node bot.cjs` (или `npm start`).
4. Проверить `node check.cjs` — покажет связь с Telegram и права бота в канале.

Хостинг должен разрешать исходящие HTTPS-запросы и держать процесс запущенным постоянно:
long polling Telegram несовместим с «засыпающими» бесплатными сервисами.

## Что важно знать про Авито

У Авито нет открытого API, а страница выдачи закрыта антиботом. Если нужен Авито,
вариантов два: добавлять найденные объявления руками в `data\manual-queue.json`
либо открывать страницу во встроенном браузере MultiTool и переносить ссылки оттуда.
