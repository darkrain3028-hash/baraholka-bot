# Перенос бота на Bothost (бесплатный тариф)

Важно: на бесплатном тарифе Bothost нельзя загрузить архив — только код из Git-репозитория.
Поэтому сначала файлы попадают на GitHub, оттуда Bothost их забирает.

## Шаг 1. GitHub

1. Откройте github.com. Есть аккаунт — войдите; нет — «Sign up», почта, пароль, подтвердите письмо.
2. Справа вверху «+» → **New repository**.
3. Repository name: `baraholka-bot`. Тип: **Public**. Нажмите **Create repository**.
4. На странице репозитория найдите ссылку **uploading an existing file**.
5. Откройте папку `baraholka-bot-deploy` на компьютере, выделите **всё содержимое** (файлы и папки `lib`, `sources`) и перетащите в окно браузера.
6. Внизу нажмите зелёную кнопку **Commit changes**.
7. Скопируйте адрес из строки браузера — он вида `https://github.com/ваш_логин/baraholka-bot`.

## Шаг 2. Bothost

1. bothost.ru → **Регистрация** (карта не нужна).
2. После входа: **Создать бота**.
3. Заполните:
   - Название: `Барахолка`
   - Платформа: **Telegram**
   - Библиотека/шаблон: **Node.js**
   - Bot Token: токен от @BotFather
   - Git URL: адрес репозитория из шага 1.7
   - Ветка: `main`
4. Нажмите **Создать бота** и дождитесь сборки. В логах должно появиться:
   `Барахолка: запуск` и `listener: бот @имя слушает команды`.

## Шаг 3. Переменные окружения

В настройках бота → «Переменные окружения»:

```
CHANNEL=-1004416972928
ADMIN_ID=412100644
REPORT_HOURS=24
COLLECT_INTERVAL_MIN=60
```

`BOT_TOKEN` платформа подставляет сама — дублировать не нужно.

## Шаг 4. Проверка

1. Убедитесь, что бот добавлен администратором канала с правом «Публикация сообщений».
2. Напишите боту в личку `список` — ответ «Обхожу площадки…», затем список вакансий.
3. Если бот молчит — смотрите логи в панели Bothost.

## Шаг 5. Обновление кода

Бесплатный тариф не обновляется сам после правок в GitHub: загрузите изменённые файлы
в репозиторий и нажмите в Bothost кнопку обновления/перезапуска.

## Если что-то не так

- `Cannot find module '/app/index.js'` — в настройках бота укажите главный файл `bot.cjs`.
- `Unauthorized` в логах — токен неверный или от другого бота.
- `Conflict: terminated by other getUpdates` — где-то уже запущена копия бота (например, на домашнем компьютере). Остановите её.
